# JOVI Smart Assist — Sprint 4

Aplicação em **Next.js** que reúne a landing page do projeto e o simulador da câmera JOVI com o
**Smart Assist**, uma IA que analisa a cena e **sugere** o melhor modo de câmera. Quem decide
ativar é sempre o usuário.

> Challenge JOVI · FIAP Engenharia de Software · Debug Team · 2026
> Entrega conjunta de **Front-End Design + Web Development** (Sprint 4).

🚧 **Em desenvolvimento.** Este README será completado ao longo da sprint.

## Evolução da Sprint 3

- Landing page (HTML/CSS Grid/JS): https://github.com/ferrazmattheuuss/jovi-smart-assist-landing-page
- Câmera em React (Web Development): https://github.com/ThiagoVitelo/SPRINT-3-WEBDEV

Na Sprint 4 as duas partes passam a ser um único projeto em Next.js com Tailwind CSS.

## Tecnologias utilizadas

- Next.js (App Router)
- React
- Tailwind CSS
- JavaScript

## Como instalar as dependências

Requer **Node.js 20 ou superior**.

```bash
npm install
```

## Como executar o projeto

```bash
npm run dev
```

Acesse `http://localhost:3000`.
